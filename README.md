# Battleship Game

A browser-based implementation of the classic Battleship game built to practice application state modeling, game logic separation, and UI interaction handling.

> Focused on structuring game logic cleanly using Test Driven Development.

## Getting Started

### 1. Clone the repo
    git clone https://github.com/sumedh27/battleship.git
    cd battleship

### 2. Install dependencies
    npm install

### 3. Run the development server
    npm run dev
